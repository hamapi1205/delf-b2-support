# 投稿カレンダー(2026年7月〜12月)

ゴール: **2,956人 → 10,000人(12月末)**
6ヶ月の物語は「**クリスマスまでに、あなたのご縁を結ぶ**」。全投稿がこの一本の物語につながります。

| 7月 | 3,700 | +750 | 願いは、届く | 七夕(7/7)・夏の始まり |
| 8月 | 4,600 | +900 | 夏の恋、動き出す | 花火・夏祭り・お盆の帰省恋愛 |
| 9月 | 5,600 | +1,000 | 月が満ちるとき | 中秋の名月・秋の新学期リセット |
| 10月 | 6,900 | +1,300 | 運命の衣替え | ハロウィン・秋の夜長 |
| 11月 | 8,400 | +1,500 | ふたりの距離 | いい夫婦の日(11/22)・冬支度 |
| 12月 | 10,000 | +1,600 | ご縁、結ばれる | クリスマス・年末の総決算 |

**週次で見る数字(プロアカウントのインサイト)**

- コメント数(ルーレット投稿の生命線)

## フェーズ1〜3の週間ルーティン(7月中旬〜12月)

**基本形: リール3本+フィード1本+ストーリーズ毎日**。曜日は固定して「習慣」にします(ファンが待つようになる)。

| 曜日 | 投稿 | 狙い |
|---|---|---|
| 月 19:00 | リール「今週の恋愛運」(台本B) | 週初めの検索需要・定番化 |
| 火 | ストーリーズのみ(質問箱「今週の恋の悩み募集」) | コアファン育成・ネタ収集 |
| 水 20:00 | **リール タロットルーレット**(台本A) | コメント爆増・自動DM起動 |
| 木 | ストーリーズ(火曜の質問に回答) | 「寄り添い」の見える化 |
| 金 20:00 | フィード 保存型カルーセル(台本D) | 保存数=リーチの燃料 |
| 土 12:00 | リール 共感語り or ご感想ストーリー(台本C/F) | 深いファン化・信頼 |
| 日 | ストーリーズ(ルーレットのDM返信裏話・今週の御礼) | 親密度・翌週への予告 |

**運用ルール**
- 投稿後60分はコメント全返信(アルゴリズム上いちばん効く時間)
- ルーレットのコメントには自動DM+**手動で「いいね」だけ**は自分で押す(寄り添いが伝わる)
- ストーリーズは1日2〜4枚。アンケート・クイズ・質問箱スタンプを毎回1つ入れる

## フェーズ別の重点

### フェーズ1: 型の確立(7月中旬〜8月)
- ルーレットを毎週水曜に固定し、「水曜はハルさんのルーレットの日」を定着させる
- 8月は花火・夏祭りデザインの限定カードを1枚追加(「今週だけのカード」で拡散を狙う)
- 自動DMの返信内容を毎月少しずつ磨く(DMへの返信率をメモ)

### フェーズ2: 拡大(9月〜10月)
- 中秋の名月・ハロウィンの限定ルーレット(シェアされやすい)
- 同規模の恋愛系・スピリチュアル系アカウントとコラボリール(相互紹介)を月1〜2本
- 伸びたリールの「型」を横展開(例: ルーレットの結果別ショート解説リール)
- LINE登録者に「月1回の限定ルーレット」を配信(リストの温度を保つ)

### フェーズ3: 収穫(11月〜12月)
- 「クリスマスまでに縁を結ぶ」カウントダウン企画(11/25開始・毎日ストーリーズ)
- 12月に個人鑑定の募集を月2回(LINE限定・先着制で希少性を出す)
- 年末「2027年のあなたの縁」スペシャルルーレット(1年の総決算・最大バズを狙う日)

## やらないことリスト(半年計画を守るため)

- フォロワー購入・自動フォロー/いいねツール(BAN・リーチ制限リスク)
- 不安を煽る断定表現(「行動しないと縁が切れる」等)→ 寄り添い路線と矛盾し通報リスクも
- 投稿の間隔を空けすぎる(リールは週3本を下回らない)
- 他ジャンル投稿(グルメ等)でアカウントのテーマをぼかす
