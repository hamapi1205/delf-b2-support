# 台本テンプレート集(穴埋め式)

【 】を埋めるだけで使えます。すべて共通のルール:

- **冒頭2秒がすべて**。悩みの言葉(音信不通・復縁・片思い)を最初の1画面に入れる
- 1リール=1メッセージ。詰め込まない
- CTA(行動のお願い)は1つだけ(コメント or 保存 or フォロー)
- 語りかけは「あなた」。断定で不安を煽らず、必ず希望で終える(寄り添いの鉄則)

---

## 台本A: タロットルーレット(毎週水曜・看板企画)

構成と動画の作り方の詳細は [tarot-roulette-guide.md](tarot-roulette-guide.md) 参照。

```
■冒頭(0〜2秒) 画面テキスト大きく:
「【今のあなたに必要なメッセージ】を1枚引きます」

■本編(2〜8秒) カード高速回転:
ナレーション or テロップ:
「深呼吸して、止めたくなった瞬間に画面をタップ。
 スクショでもOK。それが今日のあなたのカードです」

■結び(8〜12秒) 画面テキスト:
「止まったカードの【番号】をコメントしてね。
 あなただけの鑑定メッセージをDMでお届けします🕊」
```

**キャプション例:**
```
今週のあなたに、そっと寄り添う1枚を。

止まったカードの番号をコメントすると、
そのカードからのメッセージをDMでお届けします🔮

深呼吸してから、直感で止めてくださいね。
あなたが引いたカードに、偶然はありません。

#タロット占い #縁結び #恋愛占い #復縁 #音信不通
#片思い #占い好きな人と繋がりたい #タロットリール
```

## 台本B: 今週の恋愛運(毎週月曜)

```
■冒頭: 「【7/6〜7/12】あなたの恋、今週こう動きます」

■本編: 3枚のカードを順に表示(各3〜4秒)
1枚目「前半:【カード名】—【一言。例: 連絡を待つより、自分の時間を楽しむと吉】」
2枚目「後半:【カード名】—【一言】」
3枚目「アドバイス:【カード名】—【今週の合言葉。例:『焦らない人がいちばん愛される』】」

■結び: 「今週も、あなたの縁は結ばれる方へ動いています。
保存して、迷った夜に見返してね🌙」
```

CTA: **保存**。ハッシュタグに「#今週の恋愛運 #週間占い」を追加。

## 台本C: 共感語りかけ(土曜)

視聴者の心の声を代弁する型。いちばんファンが深くなる台本です。

```
■冒頭: 「【音信不通の彼のこと、まだ考えちゃうあなたへ】」
 (他の例: 既読スルー/元カレの夢を見た/友達の結婚報告がつらい)

■本編(15〜25秒):
「【共感: 眠る前にスマホを見て、また今日も連絡が来なかったって
 ため息をつく夜、ありますよね】

【視点の転換: でもね、連絡が止まっている時間は、
 ご縁が切れた時間じゃなくて、お互いの心が整う時間なんです】

【占い師としての一言: カードを引くと、この時期に無理に動いた恋より、
 待つ勇気を持てた恋のほうが、深く結ばれていくのが見えます】」

■結び: 「大丈夫。あなたの赤い糸は、ちゃんと繋がっています。
 心細くなったら、このアカウントに戻ってきてね」
```

CTA: **フォロー**(「戻ってきてね」=フォロー導線)。

## 台本D: 保存型カルーセル(金曜フィード)

7〜8枚構成。1枚目=表紙、最終枚=CTA。

```
1枚目(表紙): 「【縁が近づいている5つのサイン】」
 (他の例: 復縁前に必ず起きること/新月にやるといい縁結び習慣/
  彼から連絡が来る人がやめたこと/運命の人の見分け方)

2〜6枚目: サイン1つずつ。
 「サイン【1】:【例: 昔の持ち物が急に出てくる】」
 +2〜3行の解説(必ず「だから大丈夫」の方向で締める)

7枚目: まとめ(5つを一覧で。保存を促す)

8枚目: 「もっと深く知りたい人は、プロフィールのLINEから
 無料1枚引き鑑定を受け取ってね🕊」
```

CTA: **保存**+LINE誘導。

## 台本E: 自己紹介・世界観(月1回リメイク)

```
■冒頭: 「【なぜ私は、縁結び専門の占い師になったのか】」

■本編(20〜30秒):
「【原体験: 例: 私自身、音信不通で泣いた夜があったから】
【転機: 例: そのとき占いに救われて、待つ意味を知った】
【いま: だから私は、不安にさせる占いはしません。
 人生に間違いは一つもない。その前提で、あなたの縁を結びます】」

■結び: 「毎週水曜、あなたのための1枚を引いています。
 プロフィールから遊びに来てね」
```

## 台本F: ご感想ストーリー(隔週土曜・台本Cと交互)

```
■冒頭: 「【音信不通8ヶ月→彼から連絡が来た方のお話】」

■本編: Before(相談時の状況)→鑑定でお伝えしたこと→After(変化)
 ※必ずご本人の掲載許可を得る。個人が特定されない形に加工。
 ※「必ず叶う」とは言わない。「この方の場合は」の枠を守る。

■結び: 「あなたの物語も、まだ途中です。
 ご相談はプロフィールのLINEから」
```

## ストーリーズ小ネタ集(毎日用)

- 質問箱: 「今夜、彼に聞きたいことを1つだけ教えて」→翌日1枚引きで回答
- アンケート: 「今の恋、どっち? A:待ってる B:迷ってる」→結果に合わせ翌日投稿
- クイズ: 「縁結びに一番いい月の相は? 新月/満月」→解説で知識系ファン獲得
- 裏話: 「昨日のルーレット、いちばん多く出たカードは【○○】でした。これはつまり…」
- カウントダウンスタンプ: 水曜ルーレットの予告(「明日20時、今週の1枚」)
