# ハル 🔮縁結び師🔮 Instagram成長キット

フォロワー 2,956人(2026年7月時点) → 10,000人(2026年12月末) を目指すための実務資料一式です。

## 中身

| ファイル | 内容 |
|---|---|
| [posting-calendar.md](posting-calendar.md) | 2026年7月〜12月の投稿カレンダー(月別テーマ・週間ルーティン・KPI) |
| [reel-scripts.md](reel-scripts.md) | リール・フィード・ストーリーズの台本テンプレート集(穴埋め式) |
| [tarot-roulette-guide.md](tarot-roulette-guide.md) | 20枚高速タロットルーレットの作り方(カード画像生成プロンプト・動画手順・CTA) |
| [oracle-deck.md](oracle-deck.md) | 完全オリジナル「ハルの縁結びオラクル」全50枚(章立て・画像生成プロンプト・商品化案) |
| [auto-reply/](auto-reply/) | コメント→自動DM返信システム(ManyChat/エルグラム不要・Meta公式API・無料) |

## 全体の流れ(ファネル)

```
リール(タロットルーレット)でリーチ獲得
  → 「止まったカードの番号をコメント」でコメント爆増
  → 自動DMで鑑定メッセージが届く(auto-reply/)
  → DM末尾からLINE登録へ
  → LINEで関係構築 → 個人鑑定(マネタイズ)
```

## 使い方の順番

1. まず `tarot-roulette-guide.md` を読んで、カード20枚と最初のルーレット動画を作る
2. `posting-calendar.md` の「フェーズ0(最初の2週間)」でプロフィールの世界観を整える
3. `reel-scripts.md` の台本で週次投稿を回す
4. 並行して `auto-reply/README.md` の手順で自動DM返信をセットアップする
